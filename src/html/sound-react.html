Projet perso

Sound React — particules audio-réactives

C'est quoi, TouchDesigner ?

TouchDesigner est un outil de programmation visuelle pour créer des visuels en temps réel sur GPU. On y relie des « opérateurs », chacun spécialisé : les CHOP pour le son et les données, les SOP pour la géométrie 3D, les TOP pour l'image, les DAT pour le texte et les scripts.

Pour un développeur, son atout est que tout le réseau se pilote en Python : créer, connecter ou régler un opérateur se fait par du code. C'est ce qui permet à Sound React de tenir entièrement dans des scripts versionnés sur Git.

Le projet

Sound React est un visuel de particules qui réagit à la musique, créé uniquement avec des scripts Python — le code source complet est disponible sur GitHub. Il n'y a pas de fichier .toe dans le dépôt : à la place, trois scripts construisent tout le réseau — l'analyse du son, les particules sur GPU, le rendu et les effets. Un quatrième script fait l'inverse : il relit les réglages faits à la main dans TouchDesigner et les réécrit dans le code. Le visuel et ses réglages restent donc entièrement dans du Python.

Dans le code

Les trois scripts qui font tourner Sound React

audio_setup.py

Démo du script qui fait démarrer tout l'écosystème audio du projet

Je commence par charger le fichier audio et le brancher sur l'analyse : cela expose neuf valeurs en temps réel (low, mid, high, kick, snare, rhythm, smsd, fmsd, spectralCentroid), plus un cumul qui s'accumule dans le temps pour un mouvement qui ne se répète jamais. C'est le script le plus important du projet : toute la réactivité du visuel — tout ce qui bouge, pulse ou réagit à la musique — dépend directement de ce qui sort d'ici.

pop_setup.py

Démo du script qui construit le système de particules à partir de l'analyse audio

Ensuite, je construis le visuel : le signal audio brut devient une ligne de points, qui sert de source à un système de particules tournant en boucle sur le GPU. J'applique deux bruits et une torsion pour déformer le nuage, le tout piloté en direct par les valeurs issues de l'analyse. C'est dans ce script que se fait le lien entre le son et l'image, détaillé page suivante.

save_settings.py

Démo du script qui fige dans le code les réglages ajustés à la main

Une fois le rendu ajusté à la main dans TouchDesigner, ce script relit mes réglages actuels et les réécrit directement dans les fichiers Python. Je repars ainsi exactement des mêmes réglages à la prochaine reconstruction.
