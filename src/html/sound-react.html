Projet perso

Sound React — particules audio-réactives

C'est quoi, TouchDesigner ?

TouchDesigner est un environnement de programmation visuelle par nœuds, pensé pour créer des expériences multimédias en temps réel. Plutôt que d'écrire du code qui s'exécute de haut en bas, on relie entre eux des « opérateurs » : chacun traite un flux particulier — vidéo, audio, géométrie 3D, données — et le réseau obtenu réagit en direct à ses entrées (son, capteurs, caméras, MIDI...). C'est un outil très utilisé pour les visuels génératifs, les installations interactives, le VJing et les scénographies live, car il s'appuie sur le GPU pour un rendu en temps réel.

Les opérateurs sont classés par famille : les CHOP pour les données qui varient dans le temps (son, mouvement, chiffres), les TOP pour l'image en 2D, les SOP pour la géométrie 3D, les DAT pour le texte, les tableaux et les scripts, et les COMP, des conteneurs qui regroupent tout, y compris la logique Python.

Le projet

Sound React est un visuel de particules qui réagit à la musique, créé uniquement avec des scripts Python — le code source complet est disponible sur GitHub. Il n'y a pas de fichier .toe dans le dépôt : à la place, trois scripts construisent tout le réseau — l'analyse du son, les particules sur GPU, le rendu et les effets. Un quatrième script fait l'inverse : il relit les réglages faits à la main dans TouchDesigner et les réécrit dans le code. Le visuel et ses réglages restent donc entièrement dans du Python.

TouchDesigner Python Analyse audio Particules GPU

Les trois scripts

  • • audio_setup.py — lit un fichier audio et l'analyse : il crée le composant d'analyse et expose neuf valeurs (low, mid, high, kick, snare, rhythm, smsd, fmsd, spectralCentroid), plus un cumul de ces valeurs dans le temps pour générer un mouvement qui n'est jamais répétitif.
  • • pop_setup.py — crée le visuel : le signal audio brut devient une ligne de points, source d'un système de particules qui tourne en boucle sur le GPU. Deux bruits et une torsion déforment le nuage, piloté par les valeurs issues de l'analyse audio.
  • • save_settings.py — sauvegarde les réglages : une fois le rendu ajusté à la main dans TouchDesigner, ce script relit les valeurs actuelles et les réécrit dans les fichiers Python, pour repartir exactement des mêmes réglages à la prochaine reconstruction.

Comment le signal circule

audiofilein1 ──┬── audiodevout1          (écoute du son)
             ├── null2 ──────────────┐  (signal audio brut)
             └── audioAnalysis ── null1 ─┼── speed1
                                          │
chopto1 ◄─────────────────────────────────┘  (le son devient des points)
  └── particle1 ── random1 ── null3 ── feedback1 ── rendu & effets
