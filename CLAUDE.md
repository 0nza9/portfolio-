# Portfolio – Onza (Nathan)

Personal portfolio of Nathan, BTS SIO student (SLAM option), looking for an alternance.
All site content is in **French**; keep new copy in French with proper typography
(’ apostrophes, `&nbsp;` before `!`/`?`/`:`).

## Stack
- Static HTML pages, no framework, no bundler. Open `index.html` directly in a browser.
- Tailwind CSS v4 + daisyUI v5 via the Tailwind CLI.
  - Source: `src/css/input.css` → compiled to `src/css/output.css` (committed, linked by every page).
  - `npm run dev` watches and rebuilds `output.css`. **Rebuild after adding new utility classes**, or they won't exist.
- One shared script: `src/js/main.js` (vanilla JS, IIFE modules keyed on `data-*` attributes).
- Fonts from Google Fonts in each page `<head>`: Fraunces (headings), Inter (body), JetBrains Mono (labels/badges), Caveat (about-page sticky notes).

- RustianLife project (featured, Rust game server + Node.js/Prisma dashboard + Discord bots, 300+ member community), 5 pages linked by a sub-nav:

## Design system
- Active theme on every page: `data-theme="ardoise"` (dark slate: base #313E50 / #3A435E / #455561, text #E6E8EE, primary #8EAAE3). In ardoise, bold text is auto-colored primary.
- Alternate theme `boheme` (light cream + "Ember" palette: #220901, #621708, #941B0C, #BC3908, #F6AA1C) still defined in `input.css`.
- Look: daisyUI `card glass` panels over a fixed blurred animated background (`.bg-hero`, `bg-hero.avif` with GIF fallback, tinted per theme).
- Section labels: `font-mono text-xs uppercase tracking-widest text-primary`.
- Project card figures: banner image + slate gradient tint + logo, hover swaps in a video.
- Mobile overrides (≤640px) live at the end of `input.css`, outside `@layer`.

## main.js behaviours (data attributes)
- Clean URLs (http/https only): strips `#anchor` from the address bar via `history.replaceState` and handles same-page `#` links by scrolling without changing the URL. Strips `.html` / `index` only on non-local hosts: VS Code Live Server can't serve `/about`, so never rewrite links in JS. On Netlify, its Pretty URLs processing already rewrites `about.html` links to `/about` server-side.
- `.reveal` – zoom-in on scroll (toggles each time); `html.intro` – first-visit-per-session intro on home.
- `[data-slider]` – home project slider with dots.
- `[data-hover-video]` + `data-video-id` (YouTube) or `data-video-src` (local mp4) – hover preview.
- `[data-video-gate]` – "sound warning" overlay before playing a video with audio; auto-pauses off-screen.
- `[data-board]` / `[data-draggable]` – about-page drag.
- `[data-discord-widget]` with `data-guild-id` – live Discord member/online count.
- `[data-hn-widget]` – "Tech talk · Veille tech" marquee of French tech news (titles via textContent only).
  The `hn-` names are historical (it used to show Hacker News). It reads `src/data/feeds.js`
  (`window.TECH_TALK_FEEDS`), generated by `scripts/fetch-feeds.mjs` and refreshed every 4 h by
  `.github/workflows/feeds.yml` (static site → no browser-side RSS because of CORS). Loaded as a
  `<script>` so it works on `file://`. Change sources in the script's `FEEDS` list.
